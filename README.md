# Проект "Приложение для банка"

## Описание:

Проект "Приложение для банка" - это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/WizardoftheSafretka/Skypro.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Используйте функцию mask_account_card для маскировки номера карты или счета
2. Используйте функцию get_date для получения даты операции
3. Используйте функцию filter_by_state для фильтрации по ключу
4. Используйте функцию sort_by_date для сортировки по дате
